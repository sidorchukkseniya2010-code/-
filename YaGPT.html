Python Mini-Camp

Мини-курс по основам Python в одном файле: теория, примеры, задачи и автопроверка.

1. Основы и вывод

print() — вывод текста. Python чувствителен к отступам (обычно 4 пробела).

print("Привет, мир!")

Задача 1

Напиши код, который выводит: Hello, Python!

2. Переменные и типы

Переменные хранят значения. Основные типы: int, float, str, bool.

age = 25
pi = 3.14
name = "Анна"
is_ready = True

Задача 2

Создай переменные: city = "Москва", population = 13000000. Выведи их через запятую.

3. Условия и логика

Условные конструкции if/elif/else и операторы сравнения.

score = 85
if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
else:
    print("Нужно подтянуть")

Задача 3

Пусть temp = 22. Если temp > 25 — выведи Жарко, иначе Комфортно.

4. Циклы

Циклы for (по коллекции) и while (пока условие верно).

for i in range(3):
    print(i)

count = 0
while count < 3:
    print(count)
    count += 1

Задача 4

Выведи числа от 0 до 4 включительно с помощью for.

5. Функции

Функции позволяют переиспользовать код. Объявление через def.

def greet(name):
    return f"Привет, {name}!"

print(greet("Мария"))

Задача 5

Определи функцию square(x), которая возвращает квадрат числа. Вызови её для 5 и выведи результат.
